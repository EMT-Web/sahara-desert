# Handoff: Morocco Boutique Tours blog articles

`mbt-10-blog-articles.patch` is a `git format-patch` of one commit for the
**moroccoboutiquetours-website/Morocco-Boutique-Tours** repository (branch `master`,
based on commit 7d8467a). It adds 10 new blog articles plus blog index cards,
sitemap entries, redirects, llms.txt and three images.

Apply in a clone of that repository:

    git am handoff/mbt-10-blog-articles.patch
    git push origin HEAD:master

This folder is not part of the Visit Sahara Desert site and must not be merged
into this repository's main branch.
